## `memory/`
An **archived copy** of Claude's persistent memory for this project. Claude Code reads
memory from `~/.claude/projects/<project-slug>/memory/`, *not* from the repo — so these
files are checked in for portability and review, and are not loaded from here.

To use them on another machine, copy them into place:

```bash
mkdir -p ~/.claude/projects/-home-muddin21-WA-course-work-phd-coursework/memory
cp .claude/memory/*.md ~/.claude/projects/-home-muddin21-WA-course-work-phd-coursework/memory/
```

`MEMORY.md` is the index; each other file holds one fact with YAML frontmatter.
